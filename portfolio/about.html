Princípios que Guia Meu Trabalho

Valores que aplico em cada projeto e decisão técnica

Craftsmanship

Código não é apenas "que funciona". É arte, é engenharia. Escrevo código que outros desenvolvedores gostam de ler e manter.

Empatia com Usuário

Toda decisão técnica impacta alguém. Performance, acessibilidade, UX - não são features, são respeito pelo usuário final.

Aprendizado Contínuo

Tecnologia evolui rápido. Dedico tempo semanal a estudar: novos frameworks, papers, arquiteturas, ferramentas.

Pragmatismo

Não existe "melhor tecnologia", existe "melhor para o contexto". Escolho ferramentas pelo problema, não pelo hype.

Open Source First

Acredito no conhecimento compartilhado. Contribuo, reporto bugs, escrevo docs, crio ferramentas para a comunidade.

Sustentabilidade Técnica

Evito dívida técnica ativa. Refatoro continuamente, escrevo testes, documento decisões (ADRs), planejo migrações.
